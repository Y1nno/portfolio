# Testing Area

This folder is for experiments and unfinished work.

- `homepage-variants/` contains alternate homepage treatments and visual experiments.
- `project-page-drafts/` contains draft or non-public project pages.
- `root-before-official-build-2026-09-10/` contains the former root-level working copy before the official build was promoted.
- `promoted-official-build-source-2026-09-10/` contains the former `official-build/` folder after its contents were copied to the root.

When an experiment becomes display-ready, copy or move the needed files into the repository root.
