# Information Architecture

Website implementation is downstream of content strategy. A first-pass static implementation now exists.

## Current Rule

Do not let visual design, platform choice, animations, typography, or deployment decisions dominate before the portfolio has strong, truthful content.

## Current Implemented Structure

- Homepage: `index.html`
- Featured flagship page: `spa-game.html`
- Supporting combat-systems page: `tides-of-eternity.html`
- Public proof/completion page: `demons-dining-darling.html`
- Archived pages: `archive/boy-aflame.html`, `archive/false-god.html`
- Echoes of Us is not currently part of the public site structure.

## Likely Site Areas
