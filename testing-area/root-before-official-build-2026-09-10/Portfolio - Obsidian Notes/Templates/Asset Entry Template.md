# Asset Entry Template

Use this schema in each project [[Asset Manifest]] and in [[Asset Production Backlog]].

| Field | Instructions |
| --- | --- |
| ID | Use stable IDs like `A-001`. |
| Asset | Name the asset clearly. |
| Type | GIF, video, screenshot, diagram, code excerpt, profiler capture, build link, etc. |
| Purpose | Explain what portfolio claim this supports. |
| Competency Demonstrated | Link to [[Competency Definitions]]. |
| Current Status | existing, needed, needs-edit, blocked, approved. |
| Source / Location | File path, URL, repo path, or UNKNOWN. |
| Capture or Create Instructions | Concrete steps to produce the asset. |
| Target Case-Study Section | Context, Problem, Approach, Evidence, Reflection, etc. |
| Priority | high, medium, low. |
