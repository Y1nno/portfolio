# Interview Questions

Use this note to collect questions a skeptical senior programmer might ask after reading the case study.

## Architecture Questions

- What problem did this architecture solve?
- What tradeoffs did it introduce?
- How would it scale if the project grew?

## Implementation Questions

- Which part did I personally implement?
- What was the hardest part of the code?
- What assumptions does the system rely on?

## Debugging Questions

- What bugs appeared during development?
- How did I isolate the root cause?
- What instrumentation or tools helped?

## Collaboration Questions

- How did my work interact with design/art/audio/other programmers?
- How were shared systems coordinated?
- What did I document for other team members?
