# Snowmageddon Replacement Assessment

This note evaluates where Snowmageddon fits against the current featured trio: Spa Game / Alien Spa, Tides of Eternity, and Demons and Dining Darling.

## Current Featured Trio

Current homepage strategy:

- **Spa Game / Alien Spa:** flagship systems/simulation case study.
- **Tides of Eternity:** combat-system architecture and external-GDD-to-code translation.
- **Demons and Dining Darling:** public completion proof from a team jam.

## Snowmageddon Summary

Snowmageddon is an in-development Unity/C# arcade snowball combat project by Tiny Cowboy. Wesley joined after the initial jam/showcase phase as Gameplay Programmer / Co-Developer. Public page should refer to collaborators as lead developer and lead artist rather than personal names.

Best page spine:

1. Super Roll / bowling-ball snowball architecture refactor.
2. Data-driven pickup system refactor.
3. Variable shop spawning as production-minded level/gameplay polish.

## Recommended Portfolio Move

Best near-term option:

**Replace Tides of Eternity with Snowmageddon if Tides public-use permission is not resolved before publication.**

Rationale:

- Both occupy a combat/gameplay supporting slot.
- Snowmageddon is public-safer and has a clearer current team/studio context.
- Snowmageddon has available clips coming and does not require public-use permission from a separate rev-share project.
- Tides may still be technically deeper, especially around runtime status systems, but unresolved permission makes it weaker for a live portfolio.

Alternative:

**Replace Demons and Dining Darling only if the site needs stronger current Gameplay Programmer evidence more than public completion proof.**

Rationale:

- Demons proves shipped/public jam completion and a full playable loop.
- Snowmageddon proves ongoing collaborative gameplay implementation in a more current, more polished project.
- If the homepage can keep only three projects, Demons is the most likely to feel less aligned with "gameplay programmer / systems programmer" once Snowmageddon has clips.

Do not replace:

- **Spa Game / Alien Spa**, because it remains the strongest technical flagship.

Additional live-site cleanup:

- The current root portfolio still includes Mario World 1-1 in Unreal in the selector/navigation.
- If the goal is a stronger Unity/C# gameplay-programmer profile, Snowmageddon should replace Mario/Unreal in the featured selector before adding more projects.
- Mario/Unreal can remain archived or linked only as a breadth/learning footnote.

This second ordering is technically stronger but less completion/public-proof balanced.
