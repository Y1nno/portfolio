# Decisions

Record important strategic choices here rather than silently changing direction.

## Decision: Initialize Evidence-First Vault

- Date: 2026-08-13
- Status: approved
- Decision: Establish the vault as an evidence-first operating system for a game programming portfolio.
- Rationale: The portfolio should make a coherent argument about capabilities, not simply collect project pages.
- Alternatives considered: Start by redesigning the existing website; create only project folders; write finished case studies immediately.
- Evidence: User request and existing repository materials.
- Downstream implications: Project-specific AI instances should produce dossiers and evidence ledgers before finished public copy.
- Revisit conditions: Revisit if the portfolio goal shifts away from game programming roles.

- Date: 2026-08-13
- Status: approved
- Decision: Back off Spa Game as the immediate flagship path and analyze Tides of Eternity next.
- Rationale: Wesley clarified that the Tides contract requires requesting permission before public showing, but does not prevent internal analysis. Wesley will handle the permission request.

- Downstream implications: Tides material remains permission-gated for public release. Internal dossier, evidence ledger, asset manifest, and interview questions can proceed now.
- Revisit conditions: Revisit if permission is denied, restricted too heavily for public portfolio use, or ownership evidence is weaker than expected.

## Decision: Featured Project Lineup

- Date: 2026-08-13
- Status: approved
- Decision: Use Spa Game / Alien Spa as the flagship project, Tides of Eternity as the supporting combat-systems project, and Demons and Dining Darling as the public proof/completion project.
- Rationale: This trio creates the strongest current portfolio argument: Spa shows systems/simulation depth, Tides shows combat/status architecture, and Demons shows public delivery and jam recognition.
- Alternatives considered: Keep the old homepage order; make Tides the primary project; feature older projects before reassessment.
- Evidence: [[Project Selection]], [[Portfolio Coverage Assessment]], Spa/Tides/Demons dossiers, public Demons Itch postmortem.
- Downstream implications: The homepage should lead with Spa -> Tides -> Demons. Boy Aflame, False God, and Echoes remain additional projects until fresh dossiers justify promotion.
- Revisit conditions: Revisit if Spa lacks usable visual evidence, Tides permission is denied/restricted, or an older/additional project proves a higher-value gap.

## Decision: Archive Additional Project Pages

- Date: 2026-08-14
- Status: approved
- Decision: Remove The Boy Aflame Who Couldn't Fly, False God, and Echoes of Us from the homepage and keep the public index focused on Spa Game / Alien Spa, Tides of Eternity, and Demons and Dining Darling.
- Rationale: Wesley clarified that Unity is the stronger and more important hiring signal than Godot breadth. Additional projects risk diluting the portfolio before their evidence is reassessed.
- Alternatives considered: Keep Boy Aflame and False God as secondary cards; build out Echoes of Us for Godot breadth.
- Evidence: User direction on 2026-08-14; `index.html`; `archive/boy-aflame.html`; `archive/false-god.html`.

- Revisit conditions: Revisit only if an archived project fills a clearly distinct gap, such as replay/state capture, team process, or a role-specific requirement.
