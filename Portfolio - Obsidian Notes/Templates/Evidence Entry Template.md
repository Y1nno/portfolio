# Evidence Entry Template

Use this schema in each project [[Evidence Ledger]].

| Field | Instructions |
| --- | --- |
| ID | Use stable IDs like `E-001`. |
| Claim | Write one specific claim. Avoid bundled claims. |
| Evidence Status | CONFIRMED, LIKELY / INFERRED, or UNKNOWN. |
| Source | Link to file, repo, note, commit, screenshot, conversation, or asset. |
| What Evidence Establishes | State exactly what the source proves. |
| Ownership / Attribution | Identify whether the work was mine, shared, team-owned, or created by someone else. |
| Confidence | high, medium, low, or unknown. |
| Safe for Public Use? | yes/no. Use yes only for confirmed, attributable claims. |
| Follow-Up Needed | What would make the claim stronger or safer? |
