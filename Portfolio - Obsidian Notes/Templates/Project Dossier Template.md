# Project Dossier Template

Use [[Portfolio Dossier]] in `Projects/Project Template/` as the canonical project dossier format.

When creating a new project dossier, copy the full project template folder and rename `project: TEMPLATE` to the project name.

Minimum required outputs:

- project summary;
- role and ownership;
- technical stack;
- systems;
- implementation details;
- difficult problems;
- architecture;
- debugging;
- optimization;
- iteration;
- collaboration;
- failures and abandoned approaches;
- lessons;
- evidence summary;
- candidate code samples;
- candidate visual assets;
- interview hooks;
- competency mapping;
- uncertainties;
- unsupported claims requiring verification.
