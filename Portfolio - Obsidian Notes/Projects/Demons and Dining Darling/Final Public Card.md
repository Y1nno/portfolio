# Demons & Dining, Darling!

**Role:** Unity Developer / Gameplay Programmer  
**Tech:** Unity, C#, Ink, ScriptableObjects  
**Context:** Indie Game Academy Level 1 team jam; public browser/Windows prototype; tied for 3rd place

I built the Unity implementation for a public cooking/dating-sim prototype created with a mixed-discipline jam team. As the only programmer on the prototype, I implemented the playable systems and integrated teammate-created art, writing, and game design inputs into a working browser/Windows build.

The core loop connects timed customer orders, ingredient pickup/drop, processing stations, plating, serving validation, and Ink-driven dialogue flow. This project shows fast implementation under a short deadline: a complete prototype loop, public release, and team delivery under jam constraints.

## Evidence

- Public Itch prototype and postmortem.
- Team tied for 3rd place.
- Code proof: `OrderManager` resolving plated dishes against customer tickets and applying gameplay feedback.
- Planned visual proof: short GIF of order appearing -> ingredient handling -> station processing -> plating -> serving feedback.

## Code Proof Caption

The order system validates the player's plated dish against the active customer ticket, then applies feedback through patience, affection, and chef prompts. It is a compact example of how the prototype ties player action to game-state consequences.
