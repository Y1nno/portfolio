# Evidence Ledger

Each important claim should have an evidence entry. Public-facing copy should use only claims marked CONFIRMED and safe for public use.

## Evidence Status

- CONFIRMED: directly supported by project notes, source code, version history, documentation, conversations, assets, or another reliable source.
- LIKELY / INFERRED: reasonable conclusion from context, but not directly established.
- UNKNOWN: insufficient evidence.

## Rules

- Do not turn "we considered implementing X" into "I implemented X."
- Do not attribute team achievements personally without evidence.
- Do not upgrade LIKELY / INFERRED to CONFIRMED without a source.
- If a claim sounds impressive but cannot be traced, mark it needs-verification.
