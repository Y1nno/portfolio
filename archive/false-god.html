False God

(Role: Gameplay Programmer / Project Manager)

False God is a UI-driven roguelike dungeon crawler with turn-based combat, meta-progression, and encounter-driven decision making. Technically, it focuses on modular game systems built around low-coupling architecture, using observer-driven state updates and data-driven configuration.

What I contributed

  • Created and authored the Game Design Document (GDD) based on the designer's input.
  • Translated the GDD into a structured technical plan with system requirements and implementation milestones.
  • Designed and implemented the high-level architecture, defining core modules and system boundaries.
  • Implemented the overall game loop and combat loop.
  • Built a dedicated testing environment to validate system behavior without requiring full gameplay integration.
  • Recruited and onboarded new team members, managing and organizing work across disciplines.
  • Wrote internal documentation.

Teamwork and process

I served as both a gameplay programmer and project manager, coordinating work across a small interdisciplinary team. Early in development I worked closely with the designer daily, refining the game vision and formalizing it into a complete GDD.

I managed planning, task tracking, and documentation through Notion databases and a GDD wiki. This dramatically improved our organization, which paid off when we onboarded new members halfway through the project, helping them quickly understand the project's design goals and system architecture.

Collaboration was primarily asynchronous through Discord, with occasional voice calls for alignment and milestone planning. I also reviewed work from the other gameplay programmer to ensure code quality and consistency with the architecture.
